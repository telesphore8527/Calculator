# Retro-Modern Web Calculator

A sleek, responsive, and fully functional web calculator featuring a unique design inspired by digital displays and modern interfaces.

## 🚀 Features
* **Core Math Operations:** Performs addition, subtraction, multiplication, and division.
* **Custom Typography:** Uses *Digital-7* for a realistic retro screen and *Orbitron* for modern, sharp buttons.
* **Responsive Layout:** Beautifully designed to fit perfectly on mobile, tablet, and desktop screens.
* **Instant Reset & Erase:** Includes `AC` (All Clear) and backspace functions for seamless usability.

## 🛠️ Tech Stack
* **HTML5** - For semantic structure.
* **CSS3** - For custom fonts layout, styling, and button active effects.
* **JavaScript (ES6)** - For handling click events, display updates, and math logic.

## 🎨 Fonts Used
* **Digital-7:** Gives the display that classic, authentic digital-clock look.
* **Orbitron:** Provides a futuristic, high-tech style for the buttons.

## 📦 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/calculator
   ```
2. Navigate into the project folder:
   ```bash
   cd calculator
   ```
3. Open `index.html` in your web browser.
